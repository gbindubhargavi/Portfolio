This is my personal portfolio website built using HTML, Internal CSS, and JavaScript. The website is fully responsive and designed to showcase my profile, achievements, and work in a visually appealing and user-friendly way.

📁 Project Overview
This portfolio highlights my professional journey, educational background, technical abilities, certifications, and project work. It also includes a gallery of co-curricular activities and a contact section for easy communication.

🛠️ Technologies Used
- HTML5 : For structuring the content
- Internal CSS : For styling and layout
- JavaScript : For interactivity and responsive behavior

📚 Website Sections
- Home: A welcoming landing section with my name, tagline, and quick intro.
- About: Brief information about me, my background, passion, and goals.
- Education: Details of my academic qualifications and timeline-based representation.
- Skills: List of technical skills, soft skills, and tools I am familiar with.
- Certifications: My verified certificates with brief descriptions.
- Projects: Showcase of my major mini projects with descriptions, images, and links (if any).
- Gallery: An organized photo gallery of my co-curricular and extracurricular activities.
- Contact: Contact form and my basic details (email, phone, social links).

This portfolio website represents my skills, achievements, and journey in a simple yet visually appealing way. It serves as a digital space where I showcase my work, growth, and passion for learning new technologies. With a responsive design and smooth navigation, the site provides an engaging experience for visitors across all devices. I will continue updating this portfolio as I gain more experience, build new projects, and grow in my career.
